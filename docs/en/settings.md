# Settings (MENU)

The **// MENU** button opens the settings, which fill the whole work area; the side panels and frames stay visible. Close them with the **Close** button, the `Esc` key, or by pressing **// MENU** again. While they are open, the MENU button is lit yellow.

- **System load:** processor and memory usage with a graph of the last minute. Orange above 60%, pink above 85%.
- **Made by:** next to the version number, the **GitHub** button opens the project page (github.com/gergo85/cybershell), the globe icon opens the author's website.
- **System:** start with Windows, the Win key, open the configuration file, reload (re-reads `config.json` after manual editing and reloads every interface – same as Ctrl+Alt+R), exit. Clicking a program icon, the calendar or the weather while the settings are open closes the settings. With several monitors a program icon closes them only if the program's window comes up on the same screen as the settings.
- **Visible sections:** the Toolbar, Claude, Activity, Date, Clock, Weather, Music, Volume and Power sections of the info panel can be switched on and off one by one, and their order can be changed by dragging the handle at the start of each row. By default the Toolbar is at the top, followed by Claude, Date and Clock, with Weather, Music, Volume and Power at the bottom. On first start, laptops show only the Toolbar, Clock, Weather, Volume and Power; desktops show every section except Activity. The Start button is always first and MENU always last; the Laptop section is always right before Weather. The System card sits below this card.
- **Own Start menu:** when on (the default), the `Win` key and the info panel's **Start** button open the CyberShell Start menu, and `Win+S` and the Toolbar's **Search** icon open its search. When off, both the keys and the buttons open the Windows Start menu and search. Other Win combinations (`Win+E`, `Win+L`, `Win+Shift+S`…) work as usual. Windows does not allow the key to be captured in front of a window running as administrator; there the stock Start menu opens.
- **Appearance:** **Theme** (Dark, Light or Auto), **Language** (Hungarian or English; on first start it follows the Windows language), the position of the Icons and the panel, and **Icon names** (**Show** or **Hide**; when hidden, the Icons bar shows only the icons, without program names). The **Dark** theme is the familiar Cyberpunk 2077-style neon yellow, cyan and pink. **Light** evokes Ghost in the Shell: cool, paper-white surfaces with a fine technical grid, teal and steel-blue lines, orange-red alerts, dark ink-colored text, crisp lines instead of neon glow. Its shapes differ too: rounded, thin-line icon frames and buttons instead of cut corners, and on the screen frame dotted lines, small rings and a hatched "data capsule" instead of hazard stripes and the trapezoid. **Auto** switches with the time of day: light from sunrise to sunset, dark at night. Sunrise and sunset are calculated for the Weather location (until that is known, it is light between 7 and 19 o'clock). The theme switches instantly on every surface, without reloading.
- **Health:** reminds you to take a break when you have been working for a long time. Turn it on with the **Break reminder** switch (off by default); the **Interval** is set in minutes (5–480, 90 by default). When it runs out, a red bar appears at the top center of the work area telling you it is time for a break; its **Close** button dismisses it and the countdown starts over. The remaining time is shown only here in the settings (the ↻ button restarts it). Being away from the computer for at least 5 minutes (locked screen, lunch break) also counts as a break: the countdown restarts by itself.
- **Weather:** below Health. The **city** is free text (e.g. "Szeged" or "Wien"); on Enter or when you leave the field, CyberShell looks it up, shows the full name of the place it found next to the title (town, county, country), and the info panel's Weather section switches to it right away. An unknown place is not saved. The **Wind** switch decides whether the panel's Weather section shows wind speed and direction (on by default). Both are stored in the `weather` part of `config.json` (`city`, `wind`).
- **Panel positions:** the **Icons position** and **Panel position** rows choose separately on which screen edge the Icons and the info panel sit: **Left**, **Right**, **Top** or **Bottom**. They cannot share an edge: the edge taken by the other panel is greyed out. Thin frames run along the two remaining edges. At the top or bottom the panel contents are laid out in a row (the info panel's sections side by side), and pop-ups (calendar, weather, window preview, Start menu) open below or above the panel. If you pick two neighboring edges (e.g. left and top), the side panel gets the full screen height and the top or bottom panel runs beside it.
- **Icons:** the programs of the Icons bar (every program goes there). Reorder by dragging the handle at the start of each row, rename in the name field, choose an icon and a color; switching on the **Auto** column starts the program at sign-in (if CyberShell also starts with Windows), and the bin icon deletes it. Add a new program with the **Add program** button (exe or shortcut) or by clicking the name of a running program. Changes take effect with the **Save** button.
- **Wallpaper:** the pictures of the `wallpapers` folder as thumbnails. Clicking one sets it as the Windows wallpaper (fill, on every monitor); the current one gets a yellow frame and an "ACTIVE" tag. **Add image** lets you pick any picture (jpg, png, bmp): the program copies it into the folder and sets it right away. **Open folder** shows the folder in Explorer; pictures placed there appear the next time the settings open. **Reset** (on the second click) moves every picture added later to the Recycle Bin, so only CyberShell's own six wallpapers remain.

On start CyberShell checks whether the programs are still installed. If a program is not where `config.json` says (e.g. the file was copied from another computer), CyberShell looks for it: by the exe name in the Windows App Paths registry, among Start menu shortcuts pointing to the same exe, and finally by an identical name in the Start menu. This finds programs installed in another folder, with another version number ("Photoshop 2025" instead of "2026"), or as a Store app instead of the desktop version and vice versa; the found path is written into `config.json`. Programs that are not found anywhere do not get an icon; in the settings they are marked "NOT INSTALLED" and can be deleted there.

A small watchdog process runs alongside CyberShell (shown as a second `CyberShell.exe` in Task Manager). If the main program stops in any way, for example it is ended from Task Manager, the watchdog gives back the taskbar, frees the screen edges and exits too.
