# Settings (MENU)

The **// MENU** button opens the settings, which fill the whole work area; the side panels and frames stay visible. Close them with the **Close** button, the `Esc` key, or by pressing **// MENU** again. While they are open, the MENU button is lit yellow. Clicking a program icon, the calendar or the weather while the settings are open closes the settings. With several monitors a program icon closes them only if the program's window comes up on the same screen as the settings.

The settings are split into five tabs. The tabs are stacked in a bar on the left; below them is the computer's load (processor and memory, small), and at the bottom the author, the version number, the **Microsoft Store** button (the CyberShell page in the Microsoft Store) and the **GitHub** button (github.com/gergo85/cybershell). Switch tabs by clicking, with `Ctrl+1`–`Ctrl+5`, with `Ctrl+Tab` / `Ctrl+Shift+Tab`, or with the arrow keys on the tab bar. The settings open on the tab you used last. Except for the icon list, every change takes effect right away and is saved to `config.json`.

## Programs

The programs of the Icons bar (every program goes there). Reorder by dragging the handle at the start of each row, rename in the name field, choose an icon and a color (clicking the icon in the **Icon** column opens a matrix: the first item is the program's own icon, followed by 123 built-in icons); switching on the **Auto** column starts the program at sign-in (if CyberShell also starts with Windows), and the bin icon deletes it. Add a new program with the **Add program** button (exe or shortcut) or by clicking the name of a running program. Running programs take at most two rows (the rest scrolls), so the list keeps its height. On first start only the installed programs of the default list show; if Total Commander isn't installed, File Explorer takes its place, and the Codex (ChatGPT) app appears below Claude if it is installed. Changes take effect with the **Save** button; while there are unsaved changes, a pink mark blinks next to the Programs tab and Close asks first.

## Panels

- **Layout:** the **Icon bar** and **Panel bar** rows choose separately on which screen edge the Icons and the info panel sit: **Left**, **Right**, **Top** or **Bottom**. They cannot share an edge: the edge taken by the other panel is greyed out. Thin frames run along the two remaining edges. At the top or bottom the panel contents are laid out in a row (the info panel's sections side by side), and pop-ups (calendar, weather, window preview, Start menu) open below or above the panel. If you pick two neighboring edges (e.g. left and top), the side panel gets the full screen height. **Icon names** (**Show** or **Hide**), **On all displays** (with several monitors the panels appear on each) and **Hide Windows taskbar** (on the fly, no restart) are here too. Next to them a small screen shows the layout: the two panels, the frames and the size of the remaining workspace.
- **Sizes:** sliders for the thickness of the **Icon bar** and the **Panel bar** (Icon bar 64–96, Panel bar 80–128 px at the side and 80–100 px at the top or bottom; a thicker Panel bar moved to the top or bottom is thinned to 100 px) and of the four frames (top and bottom 0–32, sides 0–40 px). While dragging, the preview already shows the new size; it takes effect when you let go. The frame slider of an edge that holds a panel is greyed out. **Reset** restores the defaults (bars 86 px, frames 10 px); when they are already set, the button is inactive.
- **Order:** drag the handle at the start of each row to reorder the buttons of the Toolbar, Power and (on laptops) Laptop sections (Calculator, Notepad, Search, Snipping Tool; Lock, Sleep, Shut down, Restart; Wi-Fi, Battery, Network, Bluetooth); it takes effect right away (`config.json`: `sections.toolsOrder`, `sections.powerOrder`, `sections.laptopOrder`). **Reset** restores the original order.
- **Modules:** the Toolbar, Recent, Claude, Codex, Activity, Notebook, Load, Network, Clock, Date, Events, Laptop (laptops only), Peripherals (while a Bluetooth device that reports its battery is connected), Weather, Currency, Music, Volume, Background and Power sections of the info panel can be switched on and off one by one, and their order can be changed by dragging the handle at the start of each row. Recent, Claude, Codex, Activity, Notebook, Load, Date, Events, Currency and Background are hidden by default, and so is Music on laptops. The Start button is always first and MENU always last.
- **Appearance** (under Order, in three columns): the Recent, Claude, Codex, Notebook, Network, Clock, Date, Events, Weather and Currency sections can be shown **Compact** or **Normal**; the card only lists the modules that are switched on, in the same order as the Modules list. In compact view Recent shows at most 4 programs instead of 8, Claude and Codex leave out the time until reset and the refresh row, Network the chart, the Clock the seconds counter, the Date the week number, Weather the description and the city, and Currency the rate and chart; the Notebook shows 3 lines instead of 5 and Events 3 days instead of 5. On a top or bottom panel the Notebook shows as many lines (3 or 4) as fit the panel height completely, and the view sets its width; Events shows 3–4 days in one column in compact view and 2×3–2×4 days in two columns in normal view; in normal view Claude and Codex show each limit on one row (label, bar, percentage) with the two reset times side by side below them, and compact view is half as wide; Currency shows a larger rate in normal view with the change below it; the Clock seconds bar is exactly as wide as the time. The Music player and the Toolbar and Power buttons follow the panel height; the Currency rate moves below the currencies, on one line with the change, when there is room.

## Look

- **Theme & colors:** the **Theme** can be Dark, Light, Auto or Windows. **Dark** is the familiar Cyberpunk 2077-style neon yellow, cyan and pink. **Light** evokes Ghost in the Shell: cool, paper-white surfaces with a fine technical grid, teal and steel-blue lines, orange-red alerts, dark ink-colored text, crisp lines instead of neon glow, rounded frames instead of cut corners. **Auto** switches with the time of day: light from sunrise to sunset, dark at night (calculated for the Weather location; until that is known, it is light between 7 and 19 o'clock). **Windows** follows the Windows light/dark mode and switches as soon as you change it in Windows. Below are the five colors of both themes (main, second, alert, base, text) with a small sample; click any of them for a color picker, and **Defaults** restores the theme's original colors. The theme in use is tagged "IN USE". The theme and the colors switch instantly on every surface, without reloading.
- **Windows integration:**
  - **Neon border:** a thin, softly glowing frame in the theme's main color appears around the program in the foreground and follows it while moving and resizing; on a maximized window it runs just inside its edges. It is not shown for full-screen programs (games, video). **Active:** just this; **All:** the other windows' own borders take the theme color too, dimmer (Windows 11); **Off:** nothing (default).
  - **Accent color:** the Windows accent color becomes one of the theme colors (Start, Settings, active items, and title bars if enabled) and switches with the theme: **Off**, **Main**, **Second** or **Alert** (the alert color by default, because yellow and cyan are hard to read on light Windows surfaces).
  - **Windows dark/light mode:** Windows (apps and system) switches to dark or light together with the CyberShell theme, so the Auto theme switches Windows too at sunset. When the Theme is **Windows** this isn't needed, so the switch is greyed out.
  - **Windows Terminal scheme:** Windows Terminal gets a `CyberShell Dark` and a `CyberShell Light` color scheme made from the two themes, and the default profile switches between them together with CyberShell. If Terminal isn't installed, the switch is greyed out.
  - **Own desktop menu:** when on (the default), right-clicking an empty spot on the desktop opens the CyberShell menu instead of the Windows one, with the same commands (see [Desktop menu](interface.md#desktop-menu)).
  - **Own menu on desktop icons:** when on (the default), right-clicking desktop icons (files, folders) also opens the CyberShell menu, with the same commands as the Windows one. It is independent of the previous switch.

  Turning any of the Windows settings off restores the original value (CyberShell saves it when you first turn it on).
- **Wallpaper:** the pictures of the `wallpapers` folder as thumbnails, four per row (pictures added later continue below). Clicking one sets it as the Windows wallpaper (fill, on every monitor); the current one gets a yellow frame and an "ACTIVE" tag. **Add image** lets you pick any picture (jpg, png, bmp): the program copies it into the folder and sets it right away. **Open folder** shows the folder in Explorer; pictures placed there appear the next time the settings open. **Reset** (on the second click) moves every picture added later to the Recycle Bin, so only CyberShell's own wallpapers remain. When the folder holds only the built-in pictures, the button is inactive.

## Features

The cards of the Features tab follow the order of the panel's modules (as in the Modules list on the Panels tab): Start menu first, Health last. They sit in two columns, the left one top to bottom first, then the right one; every card sizes to its own content.

- **Date & time:** the **Date** format (**Auto** – based on the language –, `2026. 11. 20.`, `2026-11-20`, `20.11.2026` or `11/20/2026`; the buttons show today's date) and the **Clock** type (**24-hour** or **12-hour**, with AM/PM shown small next to the minutes). It takes effect everywhere right away: in the Date and Clock modules, for events, clipboard items and refresh times (`config.json`: `dateTime.dateFormat`, `dateTime.hour12`).

- **Weather:** the **city** is free text (e.g. "Szeged" or "Wien"); on Enter or when you leave the field, CyberShell looks it up, shows the full name of the place it found below the field ("Set to: town, county, country"), and the info panel's Weather section switches to it right away. An unknown place is not saved. The **Wind** switch turns the panel's wind display off (on by default; `config.json`: `weather.wind`). Next to the field, the °C / °F buttons of **Unit** choose the temperature unit (°C by default); the panel and the detailed forecast both use it (`config.json`: `weather.unit`).
- **Health:** reminds you to take a break when you have been working for a long time. Turn it on with the **Break reminder** switch (off by default); the **Interval** is set in minutes (5–480, 90 by default). When it runs out, a red bar appears at the top center of the work area telling you it is time for a break; its **Close** button dismisses it and the countdown starts over. The remaining time is shown only here (the ↻ button restarts it). Being away from the computer for at least 5 minutes (locked screen, lunch break) also counts as a break: the countdown restarts by itself.
- **Start menu & search:** when **Own Start menu** is on (the default), the `Win` key and the info panel's **Start** button open the CyberShell Start menu, and `Win+S` and the Toolbar's **Search** icon open its search; when off, the Windows ones open. Other Win combinations (`Win+E`, `Win+L`, `Win+Shift+S`…) work as usual. Windows does not allow the key to be captured in front of a window running as administrator; there the stock Start menu opens. **Clipboard history** shows recently copied text in search, and with the Clipboard button at the bottom of the Start menu (kept in memory only). **Web search** can be Google, Bing, DuckDuckGo or a **Custom** address (where `{q}` stands for the search text).
- **Activity:** whether the countdown starts by itself with CyberShell (**Starts by itself**) and plays a sound when it ends (**Sound**). Set its length in the panel's Activity section.
- **Calendars:** the calendars shown when you click the date. Each one's name and color can be changed, and the bin icon (on the second click) removes it. Connect a new one by pasting its "Secret address in iCal format"; **Where is it?** opens the Google Calendar settings. The settings never show the secret address, only the server name.

## System

- **General:** start with Windows, **Help texts** (on by default; when off, no hover explanations appear anywhere), and the **Language** (DE, EN, ES, HU, PL: Deutsch, English, Español, Magyar, Polski; on first start it follows the Windows language).
- **Configuration:** open the configuration file, **Reload** (re-reads `config.json` after manual editing and reloads every interface – same as Ctrl+Alt+R), **Reset everything** (on the second click every setting goes back to its default; programs, pinned Start menu items, calendars, the wallpaper, the weather location and start with Windows stay, and the old file is saved next to it as `config.backup.json`), exit.
- **System components:** the motherboard (BIOS version and date, memory slots and maximum memory), the processor (cores, threads, clock), the memory (total, the modules as text – e.g. "4 × 8 GB", or "2 × 8 GB + 1 × 4 GB" for mixed modules –, type and speed; below it the maker and part number, per group for mixed modules, and the number of empty slots), the graphics card (memory size and type, bus width, memory speed) and the storage drives in a table with comparable columns (drive, interface – e.g. NVMe or SATA –, type – SSD or HDD –, size, the letter and name of the volume on it, free space, usage with a bar). Windows doesn't report the graphics memory type, bus width and speed, so CyberShell takes them from a built-in table of common desktop AMD, NVIDIA and Intel cards; for an unknown model only the memory size is shown. Queried from Windows the first time the settings open.
- **System load:** processor and memory usage, large, with a graph of the last minute (for memory too, just the graph). Orange above 60%, pink above 85%.

On start CyberShell checks whether the programs are still installed. If a program is not where `config.json` says (e.g. the file was copied from another computer), CyberShell looks for it: by the exe name in the Windows App Paths registry, among Start menu shortcuts pointing to the same exe, and finally by an identical name in the Start menu. This finds programs installed in another folder, with another version number ("Photoshop 2025" instead of "2026"), or as a Store app instead of the desktop version and vice versa; the found path is written into `config.json`. Programs that are not found anywhere do not get an icon; in the settings they are marked "NOT INSTALLED" and can be deleted there.

A small watchdog process runs alongside CyberShell (shown as a second `CyberShell.exe` in Task Manager). If the main program stops in any way, for example it is ended from Task Manager, the watchdog gives back the taskbar, frees the screen edges and exits too.
