# Start menu and search

Two layouts sharing one search. Ideas were taken from open-source Windows launchers (PowerToys Run, Flow Launcher, Open-Shell, Seelen UI): accent-insensitive and acronym search, a calculator, running commands, starting as administrator with a key, and frequently used programs ranked first.

- **Start menu** (`Win`, or the Start button): opens next to the info panel. On the left the tiles of **pinned** programs (reorder by dragging), **frequently used** programs and **recent files**; on the right **all apps** alphabetically, with a letter jump bar on the edge. It is the same list the Windows Start menu shows as "All apps", Store apps included; help files, uninstallers and website links are left out. At the bottom your full name (as on the Windows sign-in screen) with two icons: Windows **account settings** and **sign-in options**. Next to them quick buttons (Documents, Downloads, Pictures, This PC, Windows Settings) and power: lock, sign out, sleep, restart, shut down (sign out, restart and shut down run on the second click).
- **Search** (`Win+S`, or the Toolbar's Search icon): a single search bar in the middle of the screen, with the keyboard shortcuts at the bottom. When empty it shows frequently used programs (in two columns), the clipboard and recent files. Clipboard and file items have a bin icon, and the group title has **Clear all** (deletes on the second click). Recent files are only removed from the list (and from the Windows list); the files themselves stay.
- **Typing:** searches instantly in either layout. Result groups: programs, system (lock, sleep, restart, shut down, CyberShell settings, Recycle Bin), Windows settings and system tools (e.g. "wifi", "background", "device manager"), recent files, clipboard, and finally web search. The best-matching group comes first. It finds things without accents ("fenykep" → Fényképek), by word starts, by acronym ("vsc" → Visual Studio Code) and despite typos.
- **Calculator:** the result of an expression (e.g. `12*(3+4)/2`, `2^10`, `15%*80`, `sqrt(2)`) appears instantly; `Enter` copies it to the clipboard.
- **Command:** after `>` it runs like the Run dialog (e.g. `> cmd`, `> notepad note.txt`). Folder paths (`C:\…`, `%APPDATA%`) and web addresses (`github.com`) can be opened directly too.
- **Clipboard history:** the last 30 copied texts. With an empty search the last five are shown; while typing their text is searched too, and after `v:` only these are shown (e.g. `v: invoice`). `Enter` pastes into the window the menu was opened from, `Ctrl+Enter` only puts it on the clipboard; right-click deletes an item or the whole list. It is kept in memory only (lost on exit), and anything password managers mark as hidden is left out. Turn it off with `startMenu.clipboard` in `config.json`.
- **Keys:** `↑` `↓` select, `Tab` next group, `Enter` open, `Ctrl+Shift+Enter` run as administrator, `Ctrl+Enter` open file location, `Esc` clears the search and closes on the second press.
- **Clipboard:** the Clipboard button at the bottom of the Start menu, before the folders, shows the clipboard history (same as the `v:` prefix in search).
- **Closing:** the Start menu and search close when you click elsewhere on the same screen. With several monitors, a click on the other screen, or a program coming up there, leaves them open.
- **Right-click** on a program: pin to the Start menu (or unpin), **add to Icons** (it becomes an icon right away), run as administrator, open file location.
- Frequently started programs rank higher in search as well. The web search address is set with `startMenu.webSearch` in `config.json`.
