# Start menü és kereső

Két elrendezés, közös keresővel. Ötleteket a nyílt forráskódú Windows-indítókból vettünk (PowerToys Run, Flow Launcher, Open-Shell, Seelen UI): ékezet nélküli és betűszavas keresés, számológép, parancsfuttatás, rendszergazdaként indítás billentyűvel, a gyakran használt programok előresorolása.

- **Start menü** (`Win`, vagy a Start gomb): az információs panel mellett nyílik. Bal oldalt a **kitűzött** programok csempéi (húzással rendezhetők), a **gyakran használt** programok és a **legutóbbi fájlok**; jobb oldalt **minden alkalmazás** betűrendben, a szélén betűugróval. Ugyanaz a lista, amit a Windows Start menüje „Minden alkalmazás” néven mutat, a Store-alkalmazásokkal együtt; a súgók, eltávolítók és weboldal-hivatkozások kimaradnak. Alul a teljes neved (ahogy a Windows bejelentkező képernyője mutatja), mellette két ikon: a Windows **fiókbeállításai** és a **bejelentkezési lehetőségek**. Mellettük gyorsgombok (Dokumentumok, Letöltések, Képek, Ez a gép, Windows beállítások) és a főkapcsoló: zárolás, kijelentkezés, alvás, újraindítás, leállítás (a kijelentkezés, az újraindítás és a leállítás második kattintásra indul).
- **Kereső** (`Win+S`, vagy az Eszköztár Keresés ikonja): egyetlen keresősáv a képernyő közepén, alján a billentyűparancsokkal. Üresen a gyakran használt programokat (két oszlopban), a vágólapot és a legutóbbi fájlokat mutatja. A vágólap és a fájlok tételei mellett kuka ikon van, a csoportcímben **Összes törlése** (második kattintásra törli). A legutóbbi fájloknál csak a listáról kerülnek le (a Windows listájából is), maguk a fájlok megmaradnak.
- **Gépelés:** bármelyik elrendezésben azonnal keres. A találatok csoportjai: programok, rendszer (zárolás, alvás, újraindítás, leállítás, CyberShell beállítások, lomtár), Windows beállítások és rendszereszközök (pl. „wifi”, „háttér”, „eszközkezelő”), legutóbbi fájlok, vágólap, végül keresés a weben. A legjobban illeszkedő csoport kerül előre. Ékezet nélkül is talál („fenykep” → Fényképek), szókezdetre, betűszóra („vsc” → Visual Studio Code) és elgépelésre is.
- **Számológép:** egy kifejezés (pl. `12*(3+4)/2`, `2^10`, `15%*80`, `sqrt(2)`) eredménye azonnal látszik; `Enter` a vágólapra másolja.
- **Parancs:** `>` után úgy fut, mint a Futtatás ablakban (pl. `> cmd`, `> notepad jegyzet.txt`). Mappaútvonal (`C:\…`, `%APPDATA%`) és webcím (`github.com`) közvetlenül is megnyitható.
- **Vágólap-előzmények:** az utolsó 30 másolt szöveg. Üres keresőben a legutóbbi öt látszik, gépeléskor a szövegükben is keres, `v:` után pedig csak ezeket mutatja (pl. `v: számla`). `Enter` beilleszti abba az ablakba, ahonnan a menüt megnyitottad, `Ctrl+Enter` csak a vágólapra teszi; jobb gombbal egy elem vagy az egész lista törölhető. Csak a memóriában tárolódik (bezáráskor elvész), és amit a jelszókezelők rejtettnek jelölnek, az nem kerül bele. A `config.json` `startMenu.clipboard` értékével kapcsolható ki.
- **Billentyűk:** `↑` `↓` választás, `Tab` a következő csoport, `Enter` megnyitás, `Ctrl+Shift+Enter` futtatás rendszergazdaként, `Ctrl+Enter` a fájl helye, `Esc` törli a keresést, másodszorra bezár.
- **Jobb gomb** egy programon: kitűzés a Start menübe (vagy levétel), **hozzáadás az Ikonokhoz** (rögtön ikon lesz belőle), futtatás rendszergazdaként, a fájl helyének megnyitása.
- A gyakran indított programok a keresésben is előrébb kerülnek. A webes keresés címe a `config.json` `startMenu.webSearch` értékével állítható.
